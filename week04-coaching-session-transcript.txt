COACH: That's a great guess and you're essentially correct! Let me fill in the
details:

PostgreSQL returns date values as JavaScript Date objects. When you call
.toISOString() on one, you get a string like "2026-06-03T00:00:00.000Z". The

to parse it, so the field would appear blank.

--------------------------------------------------------------------------------

FERNANDO: Client side validation is focused on providing quick feedback to the

COACH: Perfectly stated. Client-side validation is a UX convenience; server-side
